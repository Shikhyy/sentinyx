What happens when an agent reads a poisoned token.

001 / It reads the text

Your agent fetches the token’s description to decide on a swap. The hidden order comes in with everything else.

002 / Guard quarantines it

A separate model with no tools reads the text and hands back only a typed value, like an address. It can’t act on anything it read.

003 / The value is tagged

That address is marked as coming from untrusted text, and the mark follows it through every step.

004 / The transfer is checked

Before signing, Guard asks one question: did the recipient come from you, or from something the agent read?

005 / Nothing is signed

The transfer is stopped, and in the morning you get a trace showing exactly which line tried to steer your agent.
